# Historical Plans and Specifications

The files under `plans/` and `specs/` are dated engineering records. They explain why a capability was designed and how it was implemented at that point in the project.

They are intentionally preserved, including old workspace paths, server aliases, phase names, and checklist state. Those details are historical evidence, not current setup instructions and not a backlog by themselves.

For current usage, start with:

- the repository [README](../../README.md) or [中文 README](../../README.zh-CN.md);
- the [current documentation index](../README.md);
- [installation](../installation.md), [operations](../operations.md), and [security](../security.md).

Active development checkouts may also contain a local `HANDOFF.md`. That file is the current-state engineering index, while this directory remains an immutable record of earlier design work.
